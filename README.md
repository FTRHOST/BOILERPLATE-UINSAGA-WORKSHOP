# Interactive Personal Portfolio - Starter Template

Halo! Selamat datang di **Starter Template** untuk acara Live Coding Web Modern.
Template ini dibuat menggunakan **React (Vite)** dan **Tailwind CSS**. Di sini kita tidak menggunakan TypeScript agar kode JavaScript-nya lebih mudah dipahami oleh pemula.

Tugas kamu adalah melengkapi, mengubah, dan mempercantik halaman portfolio ini sesuai dengan instruksi yang akan diberikan.

---

## 🚀 Cara Memulai (Persiapan)

Ikuti langkah-langkah di bawah ini untuk menjalankan project di komputermu:

### 1. Instalasi Node Modules
Buka terminal (atau Command Prompt) kamu, pastikan kamu berada di dalam folder project ini. Lalu jalankan perintah berikut untuk mengunduh semua *dependencies* (paket tambahan) yang dibutuhkan:

```bash
npm install
```

*Tunggu beberapa saat sampai proses instalasi selesai.*

### 2. Menjalankan Server (Local Development)
Setelah proses instalasi selesai, kamu bisa menyalakan server lokal dengan mengetikkan perintah berikut:

```bash
npm run dev
```

### 3. Membuka di Browser
Setelah menjalankan perintah di atas, kamu akan melihat sebuah URL (biasanya `http://localhost:5173/`). Buka URL tersebut di browser web favoritmu (Chrome/Firefox/Safari) untuk melihat tampilan websitenya secara langsung (Live Preview).

---

## 📂 Struktur Project

Berikut adalah lokasi file-file penting yang akan kamu edit selama acara:

- `src/App.jsx` - Komponen utama yang membungkus seluruh halaman.
- `src/components/Navbar.jsx` - Komponen untuk navigasi (menu) di atas.
- `src/components/Hero.jsx` - Bagian perkenalan diri dengan foto profil dan tombol "Like".
- `src/components/Projects.jsx` - Bagian portofolio untuk menampilkan project-projectmu.
- `src/index.css` - File CSS tempat konfigurasi Tailwind dan gaya custom jika diperlukan.
